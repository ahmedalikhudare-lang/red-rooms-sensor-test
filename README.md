# RED ROOMS — اختبار حساس الكاميرا (نسخة تجريبية)

نسخة أولية تختبر طور البث الحقيقي: كاميرتك ومايكك يقررون إذا نجوت من الدمى الثلاث.

**جرّبها من هنا:** https://ahmedalikhudare-lang.github.io/red-rooms-sensor-test/

| الدمية | القاعدة | لو خالفت |
|---|---|---|
| PF-01 الأب (يسمع) | اثبت قدام الكاميرا: لا تتحرك، لا ترمش، لا تحرك عيونك، ولا تسوي صوت | جمب سكير |
| PF-02 الأم (تشوف) | لا تخلي الكاميرا تشوف وجهك | جمب سكير |
| PF-03 الطفل (يحس بالنظرات) | غمّض عيونك الاثنتين ووجهك مكشوف | جمب سكير |

- اضغط 1 / 2 / 3 للدمى، أو "ليلة عشوائية".
- ⚠ صوت الجمب سكير عالي.
- كل المعالجة على جهازك (MediaPipe)، ما يتسجل ولا يترسل شي.
- يحتاج متصفح كروم أو إيدج، وإذن الكاميرا والمايك.
